01 — Concept

What is Lagrange Interpolation?

Lagrange interpolation is a numerical method used to find a polynomial that passes exactly through a given set of known data points. We use other points on the function to get the value of the function at any required point.

Key Idea

Given points \((x_0, y_0), (x_1, y_1), \dots, (x_n, y_n)\), there exists a unique polynomial \(P(x)\) of degree at most \(n\) such that \(P(x_i) = y_i\) for all \(i\).

02 — Formula

The Lagrange Formula

The interpolating polynomial is given by:

\[ p(x) = \sum_{i=0}^{n} y_i \prod_{\substack{j=0 \\ j \neq i}}^{n} \frac{x - x_j}{x_i - x_j} \]

Each term is the data value \(y_i\) multiplied by the Lagrange basis polynomial \(l_i(x)\).

03 — Derivation I

The Polynomial Form

Assume the function \(y = f(x)\) can be represented by a polynomial of degree at most \(n\):

\[ y = a_0(x-x_1)(x-x_2)\dots(x-x_n) + a_1(x-x_0)(x-x_2)\dots(x-x_n) + \dots + a_n(x-x_0)(x-x_1)\dots(x-x_{n-1}) \]
04 — Derivation II

Solving for Coefficients

Substitute each data point to solve for the coefficients \(a_i\):

\[ a_i = \frac{y_i}{\prod_{\substack{j=0 \\ j \neq i}}^{n} (x_i - x_j)} \]

Substituting back gives the complete Lagrange form.

05 — Case Study

Problem Setup

Use Lagrange’s interpolation formula to find \(f(10)\) given the unequally spaced data points:

\( x \)56911
\( f(x) \)12131416
06 — Formula Application

Lagrange Expression

\[ f(x) = \frac{(x-6)(x-9)(x-11)}{(5-6)(5-9)(5-11)}(12) + \frac{(x-5)(x-9)(x-11)}{(6-5)(6-9)(6-11)}(13) \] \[ + \frac{(x-5)(x-6)(x-11)}{(9-5)(9-6)(9-11)}(14) + \frac{(x-5)(x-6)(x-9)}{(11-5)(11-6)(11-9)}(16) \]
07 — Calculation

Substitute x = 10

\[ f(10) = \frac{(10-6)(10-9)(10-11)}{(5-6)(5-9)(5-11)}(12) + \frac{(10-5)(10-9)(10-11)}{(6-5)(6-9)(6-11)}(13) \] \[ + \frac{(10-5)(10-6)(10-11)}{(9-5)(9-6)(9-11)}(14) + \frac{(10-5)(10-6)(10-9)}{(11-5)(11-6)(11-9)}(16) \]

Term-by-term evaluation:

First term: \( 2 \)
Second term: \( -4.333333 \)
Third term: \( 11.666667 \)
Fourth term: \( 5.333333 \)
08 — Result

Final Value

\[ \mathbf{f(10) = 14.666667} \]
Interpretation

The unique polynomial of degree 3 that passes exactly through the four given points evaluates to 14.666667 at \(x = 10\).

09 — Practical Uses

Where is this Used?

  • Data Analysis: Estimating values from irregular sensor readings.
  • Computer Graphics: Smooth curve rendering between control points.
  • Engineering: Approximating functions in simulations and signal processing.
  • Numerical Methods: When data points are not equally spaced.
10 — Advantages

Why Lagrange?

Key Benefits
  • Works with unequally spaced data points
  • Direct formula — no difference table required
  • Easy to implement in code
  • Polynomial passes exactly through all given points
11 — Workflow

Summary of Workflow

1. List the known points \((x_i, y_i)\).

2. Write the Lagrange basis polynomials \(l_i(x)\).

3. Form the full polynomial \(p(x) = \sum y_i l_i(x)\).

4. Evaluate at the desired \(x\).
