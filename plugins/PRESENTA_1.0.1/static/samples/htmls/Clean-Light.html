Vulnerability Management

OWASP ZAP 2.9

Getting Started Guide

Security testing for modern web applications.

01 / OVERVIEW

What is ZAP?

The Zed Attack Proxy is an open-source DAST tool used to discover security risks in running applications.

The Proxy

Acts as a Man-in-the-Middle, allowing ZAP to intercept and modify traffic.

Who is it for?

Developers, functional testers, and security professionals.

02 / CONCEPTS

Testing Terminology

Assessment

Analysis and discovery of vulnerabilities without attempting to exploit them.

Testing

The discovery and attempted exploitation of weaknesses to prove risk.

ZAP supports both "Safe" assessments and aggressive "Active" testing.

03 / METHODOLOGY

The ZAP Workflow

Step 1: Explore

Crawl the application manually or via automated spiders.

Step 2: Attack

Execute active scans against discovered endpoints.

Step 3: Remediate

Review the Alerts tree and fix the identified vulnerabilities.

04 / DISCOVERY

Automated Discovery

Standard Spider

Crawls HTML links and resources. Fast and effective for traditional sites.

AJAX Spider

Interacts with the browser to discover elements in JS-heavy apps (React, Vue).

05 / ANALYSIS

Passive Scanning

By default, ZAP analyzes every request and response passing through the proxy without modifying them.

Benefits

It is non-intrusive and safe for production environments. It identifies missing security headers, PII leaks, and cookie misconfigurations.

06 / ATTACK

Active Scanning

This is where ZAP sends actual malicious payloads to trigger vulnerabilities.

Common Checks

SQL Injection, Cross-Site Scripting (XSS), and Path Traversal.

Safety Warning

Active scanning can modify data or crash services. Use only on authorized targets.

07 / INTERFACE

Heads Up Display (HUD)

The HUD is a revolutionary interface that brings ZAP's features directly into your web browser.

  • • Launch scans from the sidebar in your browser.
  • • View page alerts as you navigate.
  • • Manipulate data on-the-fly without leaving the app.
08 / CI/CD

ZAP Automation

REST API

Control ZAP via external scripts (Python, Java, Node.js).

Daemon Mode

Run ZAP headless in your build pipeline to gatekeep production releases.
