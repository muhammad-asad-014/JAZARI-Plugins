Project Baseline

OWASP ZAP 2.9

The Intelligent Path to Web Application Security

01 / Foundation

Core Purpose

ZAP is a Dynamic Application Security Testing (DAST) tool designed for users with various levels of security experience.

The Proxy

It intercepts every request between your browser and the app, letting you inspect and modify data in transit.

Accessibility

Built for developers and functional testers who need a reliable way to find vulnerabilities early.

02 / Methodology

Explore & Attack

Assessment

Analysis and discovery of risks without triggering them.

Testing

Discovery followed by attempted exploitation to prove real impact.

The Workflow

1. Explore the App → 2. Run Automated Spiders → 3. Execute Active Scans → 4. Review Alerts.

03 / Automation

The Spiders

Discovery is the most important step. ZAP offers two ways to map your target:

Standard Spider

Fast and robust. Parses HTML to find links. Ideal for classic server-side apps.

AJAX Spider

Modern and thorough. Interacts with the browser to find elements in React/Angular/Vue apps.

04 / Environment

Desktop Layout

Sites Tree

A nested view of every URL discovered. Use this to focus on specific Contexts.

Information Window

Where the history of every request lives, alongside the list of found Alerts.

05 / DevOps

Automation & API

ZAP is built for the modern CI/CD pipeline.

ZAP API

Trigger scans and export reports via JSON. Fully scriptable with Python or Java.

Daemon Mode

Run ZAP headless in your build environment to gate keep code releases.
