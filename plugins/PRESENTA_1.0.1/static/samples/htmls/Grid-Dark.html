// METHODOLOGY

The Workflow

EXPLORE Discover all pages, parameters, and endpoints in the target.
ATTACK Simulate malicious exploits to prove if a vulnerability exists.
REPORT Document findings, risk levels, and remediation steps.
// AUTOMATION

Spiders & Scanners

ZAP offers two ways to map an application automatically:

Traditional Spider: Analyzes HTML for links. High speed.
AJAX Spider: Used for JS-heavy apps. Crawls by interacting with the UI.
// ANALYSIS

Understanding Alerts

ZAP categorizes vulnerabilities by severity:

High   Critical risk, exploit proof found.
Medium   Significant risk, requires attention.
Low   Minor issues or best practices.
